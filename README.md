# UPI Payment Performance Analysis

A beginner-friendly FinTech analytics project built using **Excel** and **Power BI**.

## Project Overview
This project analyses **5,000 simulated UPI transactions** to understand payment performance and transaction patterns.

## Dashboard Highlights
- Total transactions, successful transactions, failed transactions, and success rate
- Bank-wise transaction performance
- Breakdown of failed payments by reason
- Hourly transaction activity
- City-wise transaction volume and transaction value

## Tools Used
- Microsoft Excel — data checking, preparation, and pivot analysis
- Power BI — interactive dashboard and visual analysis

## Dataset
The dataset is simulated for learning and portfolio demonstration. It is **not real PhonePe, bank, or customer transaction data**.

## Files
The Power BI dashboard and supporting dataset will be added to this repository.

## Purpose
To demonstrate practical data cleaning, analysis, dashboard creation, and business-insight presentation skills.
